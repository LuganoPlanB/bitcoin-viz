# Verification

## Current checks

```sh
cmake --preset release
cmake --build --preset release --parallel 2
ctest --preset release
cmake --preset sanitize -DCMAKE_CXX_COMPILER=clang++
cmake --build --preset sanitize --parallel 2
ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 \
  UBSAN_OPTIONS=halt_on_error=1 ctest --preset sanitize
```

The native-only suite contains:

- `native-contract`: 36 model/platform cases including exact satoshis and wire
  decoding, atomic rollback, reversed undo, pending overlays, retention, visibility,
  peer sessions/deltas, capture continuation/fairness, writer exclusion, UTF-8
  paths and an actual libzmq subscriber (IPC on POSIX, loopback TCP on Windows
  or when the temporary directory exceeds the Unix-socket path limit).
- `cli`: executable identity/version, default database, synthetic demo, all three
  Gource modes, status, journal output, replay and invalid-command/option rejection.
- `release-tools`: temporary Git candidates, strict versions, clean/base guards,
  bundle verification, repeat preparation, five fixture platform archives,
  dependency licenses, manifests, checksums and incomplete-set rejection.

The removed implementation's parity oracle and interpreter-driven HTTP observer
integration are no longer part of the suite. The native contracts do not establish
end-to-end cookie/session recovery against a live Core node. Cross-platform release
jobs provide platform evidence only after actually running on their target runners.

## Historical real signet evidence

The native-only migration was checked on Linux x86_64 with GCC 14.2 and Clang 19.1:
all three CTest suites passed in release and ASan/UBSan builds, with 36 passing
native contracts. Installation and the installed executable's version were also
checked. The long session temporary path required the test's loopback TCP fallback.
Matching Debian libcurl development headers were extracted under the ignored
`.tools/native-deps/sysroot` and selected using `CURL_INCLUDE_DIR`; `CURL_LIBRARY`
pointed to `/usr/lib/x86_64-linux-gnu/libcurl.so.4`. ccache used `build/.ccache`.
No new live-node or desktop-platform run was performed for this migration.

[verification-native-signet.json](verification-native-signet.json) preserves an
earlier C++ signet run, including the executable's original path and a legacy
database compatibility result. This report predates the rename and is historical
evidence rather than a new test run.

Against Core 32.1, the observer tracked two blocks ending at height 231914 and
followed ZMQ disconnect/readmission/reconnect. It reconciled 535 readmitted
memberships, removed them on confirmation, restored 6,260 output records exactly,
and passed 20 `gettxout(..., false)` checks. The sorted-coin digest was:

```text
402115f649d73d1e86df75d244bd56142bf7acba2776fbbe21f6036bd6b9affb
```

Core was still in initial download; this validates its partial signet chain,
not complete signet synchronization or full-current-UTXO coverage. No mainnet-scale
or sustained-throughput claim follows from these observations.

## Recorded Gource scenes

The retained previews were generated by the C++ renderer from that historical
signet database. Gource read custom logs through stdin and ffmpeg produced the
videos. Protocol targets came from earlier captured messages; they were not all
arriving at screenshot time. The UTXO scene selects 200 of 6,260 outputs; the state
scene has two blocks, an empty mempool and no peers while networking was paused.

avatar choreography. Current-scene exports can be repeated with:

```sh
bitcoin-viz render --db PATH.sqlite --once --mode protocol >protocol.gource
cat protocol.gource | gource --log-format custom --file-idle-time 0 --stop-at-end -
```
